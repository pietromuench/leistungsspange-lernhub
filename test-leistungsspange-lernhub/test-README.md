# leistungsspange-lernhub
Lernhub zur Vorbereitung auf die Leistungsspange der Deutschen Jugendfeuerwehr im Landkreis Oberspreewald-Lausitz

## Enthaltene Tools
- **Gruppenführer-Befehle** – Marsch, Meldung & komplette Löschangriff-Befehlsgebung mit interaktivem Quiz
- **Fragenbeantwortung** – Alle Fragen der Broschüre als Karteikarten, nach Themenbereichen filterbar
